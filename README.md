# Venture Roleplay website

A cinematic, responsive Vite + React site for VentureRP.

## Run locally

```bash
npm install
npm run dev
```

Build the production bundle with `npm run build`.

## Editing content

- Community rules: `src/data/rules.json`
- Team members: `src/data/team.json`
- Discord invite and site name: `src/config.js`
- Cinematic backgrounds: `public/images/`

The supplied Google Doc currently ends mid-sentence in rule 3.1. That fragment is retained and clearly flagged in the UI so it can be completed without silently inventing policy text.
